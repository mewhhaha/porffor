lila

Swedish for purple. Formerly Porffor.

Lila is a greenfield Rust compiler that translates JavaScript directly to WebAssembly ahead of time. It is an ambitious research project, not yet a general-purpose JavaScript runtime.

Architecture

JavaScript source → parsing and early errors → spec-shaped IR → lowering IR → real Wasm code generation. Emitted programs are compiled user code, not an interpreter or VM bundled into Wasm.

Build and run

git clone https://github.com/mewhhaha/porffor.git
cd lila
./scripts/dev.sh build
./target/debug/lila run program.js
