slots produce lossless singleton strings before a host query, including unknown,

[CollationsOfLocale](https://tc39.es/ecma402/#sec-collationsoflocale) uses the
existing admitted Collator lookup-matched locale's sort map. It does not call
formatting resolution or expose a global union. Null/standard/search/searchjl
are removed; unmatched languages use emoji/eor, and names sort lexically.

[TimeZonesOfLocale](https://tc39.es/ecma402/#sec-timezonesoflocale) reads only
the original immutable base-region slot. Missing returns undefined locally;
rg, sd, likely subtags, transformed and private language text cannot supply it.

canonical primary IANA names, or an empty list. There is no world001 union.

## Wire and allocation

A request has u64 version 1, request tag operation*2, u64 locale byte length and
canonical locale bytes. A response has version 1, tag operation*2+1, u64 count,
then u64 length/ASCII bytes for each name. The existing capacity handshake first
measures required bytes, allocates exactly that span, and requires exact Written
length. Rust typed records and Wasm checks enforce header, bounded extent,
count/array-size limits, identifier domains and exact trailing-byte exhaustion.
The private non-Copy checked carrier is the sole materializer input. Scratch
locals follow strict reverse reservation order. Dense entries use HEAP_PTR_OFFSET
backing storage, String payloads and normal writable/enumerable/configurable
attributes. Array allocation uses the called function's defining Realm, not
public constructors or the receiver Realm. Results publish after validation.
