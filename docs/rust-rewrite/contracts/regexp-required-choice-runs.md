# Required RegExp choice runs

The counted Required End has a second consumed proof for bodies with surviving
ordinary or progress alternatives. It emits a compact run in the matcher's linked
choice arena. Each virtual iteration retains every fallback in original LIFO
order. This is an alternative-preserving representation, not a no-match cutoff
or a claim that equal input cursors prove replay.

Two successful mandatory iterations must exist first. Their complete surviving
Snapshot groups must have the same length, actual choice kinds, source origins, fallback PCs,
three cursor words, captures and other repetition rows. The authorized outer
row must be active and Required at the same UTF-16 cursor; its exact minimum and
finite maximum must be the current values in the newest group and those values
plus one in the preceding group. All source-sized base-10^9 limbs and canonical
used lengths are checked. The older group must end exactly at its boundary.

The entire Guard-to-End body is classified before the proof is published. Every
Split and Jump target stays in that body, including its paired End. Nested
counted pairs use the original v3 admission, require a distinct row and an
inactive post-body state, and retain canonical counters. Their full physical
source is scanned. Optional, zero-bound and choice-owning children participate
in the complete snapshot comparison; a nested Guard can be the deterministic
primary point. No child counter becomes part of the affine outer row.

A discharged lookaround extent uses the same physical scanner as required-empty
replay. Its exact sentinel, reciprocal End/Failure, polarity, parent direction and
bounded internal targets must be proven. Its real execution has discarded all
private choices and restored cursor/repetition state; only then may the body
scan advance past that whole extent. Required-empty replay retains its input-only
rule. The Run admits capture writes and backreferences because its actual two
complete templates also compare every capture word. Nested lookarounds use a
source-sized iterative ancestry proof with exact parent direction and polarity.
Every ordinary/progress edge stays within its actual assertion owner, including
edges outside an assertion that would otherwise enter its private body. The
temporary GC byte array scales with admitted source instructions, never with a
quantifier bound. A separate linear source pass certifies canonical nested
ProgressSplit/ProgressCheck attempts. Primary entry, fallback, reciprocal Check and
repeat/exit continuation are exact. Ordinary edges cannot enter or leave an
attempt's private source scope. An orphan Check cannot consult a frame from an
older iteration as a substitute for a current Split.
Capture reads and writes, input atoms and boundary assertions
use their original matcher. The body therefore cannot inspect the changing
outer counter or scan a continuation below its oldest surviving current-iteration entry.

At that oldest actual choice, the two templates witness equal complete machine
state except the authorized affine outer row. Its primary PC, immutable input,
direction and program are the same. The successful suffix cannot pop that
surviving entry. Thus it produces the same post-body state on both iterations.
The next iteration starts from that same state and follows the same prefix and
suffix; all its saved continuations have the same template. Neither the proof
nor the run removes an alternative based on its apparent success or emptiness.

The run replaces only those two observed groups and the remaining future
mandatory groups. Earlier choices stay linked below it. Its immutable template
contains the complete newest Snapshot slab. Source-sized exact counters record
remaining virtual iterations and the affine minimum to restore. After a whole
template is consumed, the former decreases and the latter increases. The newest
virtual group restores minimum one; each older group restores two, three and so
on. Finite maximum restoration is the post-batch maximum plus that exact
minimum. Active, Required and PreUtf16 retain the validated template metadata.
The actual End subtracts the intact mandatory minimum from finite maximum,
publishes the run while that minimum is still available, then clears minimum.

Run backtracking restores each fallback's full captures and other counter rows
before replacing only the authorized min/max used lengths and limbs. Assertion
and progress scans retain their original Ordinary/failure-PC and progress-origin
rules through a checked logical entry view. A scan searches the current partial
template, then at most one older full template: its predicates depend on original
kind/fallback/origin, which do not change between older groups. Selected virtual
restoration applies the selected group's exact affine row; truncation discards
only its newer entries and that selected entry, retaining all older entries and
groups. A lazy Choice keeps its current entry as an Attempt; a failed Attempt
retires without resuming its stale fallback. One current-entry override leaves
every older group's immutable template intact. The arena uses byte
offsets and a separate used frontier, so the decimal count does not become a
machine-word frame depth or a bound-sized allocation.

Failure acceleration has a separate executed trace. Consuming the oldest entry
by real backtracking records a pending complete group only if none of its
fallbacks reached the authorized counter's actual End. The selected final
fallback must still fail and return to that same active Run before older groups
can retire. An End clears the pending trace before reading counter-dependent
semantics. Assertion truncation never establishes this evidence and taints its
selected Run; selecting or appending another Run invalidates the prior trace.
Removal and reset clear its workspace authority. Thus equal templates alone do
not establish that their alternatives failed, and a successful atomic assertion
cannot substitute for executed failure.

Literal and computed constructor controls cover huge empty alternatives,
multiple fallback templates, body-written numbered/named references, preceding
virtual iterations, finite optional continuation and reverse matching. Small
controls cover complete exhaustion, completed child counters and excluded
progress forms. Further cohorts cover optional child Guard fallbacks and discharged
positive/negative input assertions, their private progress choices, actual outer
virtual fallbacks, both lookaround directions, capture-writing assertions and
nested positive/negative/reverse assertions, and discharged child counters.
Live nullable progress cohorts cover original priority, named capture restoration,
astral indices, atomic assertion truncation, reverse matching and finite exhaustion.
Huge failure cohorts cover whole-group exhaustion and capture restoration across
the original older fallback after the compact Run retires.
These controls are authored and unrun. No compilation, formatting or
runtime result is claimed.

The producer also recognizes structural pure epsilon composition. Empty sequences,
concatenations, alternations, noncapturing groups and repetitions of only that
language have no capture, input, assertion or failure effect. Literal lowering
and the original runtime compiler's checked bottom-up node pass elide those
instructions before publishing the descriptor. Parsing and capture/name/bound
validation still precede the shortcut. Capture groups, backreferences, anchors,
lookarounds and finite string sets cannot acquire the certificate; a surrounding
capture or assertion retains its own real operation. This closes huge nested
empty-choice failure without weakening the Run's executed-End witness or clipping
any counter of an effectful expression.

The recursive producer now measures the actual contiguous template byte span,
walks each immutable tree leaf once and compares both captured current playback
and original child-reset domains. Its physical reader and playback are now
authored as one joined source slice. A nested node retains its own source row;
only the outer authorized row is affine in the producer comparison. Copied
partial child playback must begin tainted, while its own actual full-group advance
can establish a new failed-continuation trace. These tree controls are authored
and unrun; compilation and runtime verification of the joined source remain
deferred to the batch checkpoint.

The run proof still excludes active post-body child repeats, outward edges and
successful bodies without a surviving template. Completed pure greedy attempts
without surviving choices have their separate required-empty proof. General
effectful alternatives which reach End and recreate equivalent required runs
need a separate complete continuation-cycle authority. A stronger whole-body
proof handles iteration-independent bodies whose capture writes are dominated
by their actual entry Clear and whose child/progress owners are fresh. It proves
ordered continuation stabilization above the UTF-16 input bound, translating
minimum and maximum by the same skipped count. All-path zero-width bodies retain
one actual iteration. The exact optional gap and last-iteration priority remain
as described in `regexp-independent-counted-repetition.md`. Equal cursor or
equal capture values alone do not provide it. Unproved owner/reset shapes retain
the original path. No resource ceiling, timeout or failure result has changed.
