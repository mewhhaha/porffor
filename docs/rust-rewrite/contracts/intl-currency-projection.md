# Paired localized currency projection

Custom manifest version 2 and the SDK currency selection consume one checked
list of canonical CurrencyCode values. The existing nine-argument locale
constructor is unchanged. `for_currency_codes` retains all original public
locales; `with_currency_codes` composes the same selection with existing locale
filters. A code must have actual pinned localized data, rather than only satisfy
NumberFormat's syntactic currency option grammar.

Number's native producer filters actual CurrencySet labels and per-currency
numbering overrides. Its typed dense closure removes text, name choices and
patterns reachable only from omitted currency rows. Complete numbering systems,
units, fractions, Unicode roots, cardinal/ordinal rules and private RelativeTime
and Duration dependencies remain on the original immutable owner.

DisplayNames filters only actual Currency entries, retains every other selected
name domain, deduplicates the resulting pools and remaps all associations. Both
images use schema-2 descriptors binding canonical codes, source pins, selected
locale rows and original foundations. Admission rederives the complete physical
payload. Only the resulting private catalogue can admit an empty localized
currency set or pool; full pinned-source admission keeps its original checks.

Provider setup requires exact agreement between the Number and DisplayNames
currency domains. Re-admission of exported frames checks the same condition,
even for images carrying the same Custom ID. Supported currency values derive
from actual public Number rows and genuine names in the retained DisplayNames
default locale. Other supported-value authorities are unchanged.

An omitted currency remains a valid syntactic NumberFormat option. Its original
code fallback, complete fraction digits and general layout apply. DisplayNames
uses its existing code or undefined fallback. Selected codes retain their real
localized symbols, names and overrides. No USD row, alias locale or replacement
profile is inserted to make an empty pool appear complete.

The currency cache field binds presence, count and canonical length-prefixed codes.
CLI manifest admission occurs before user source loading; canonical exports and
SDK/CLI compilation consume the same selected twelve-image graph. Authored
controls cover physical reductions, selected formatting parity, omitted-code
fallbacks, global authority retention, damage and mismatched-image refusal,
manifest bounds, cache identity and actual emitted Wasm behavior. They remain
uncompiled and unrun. Localized calendar selection now has its separate producer
and consumer closure. Numbering-system selection now composes through the paired
Number/DateTime factories; named-zone selection now has its actual transition and
dependent-name closure. Actual service/frame selection remains unfinished source
work. See the [numbering contract](intl-numbering-projection.md) and
[named-zone contract](intl-named-zone-projection.md).
