# JSON parse frame-state authority

## Scope

This contract owns the private state words used by the iterative dynamic JSON
parser in `crates/lila-aot-wasm/src/builtins/json.rs` and the validated-local
lifecycle in its private `json/parse_frame_state.rs` child. It does not own
JSON token grammar, value decoding, parse metadata, reviver traversal or
`JSON.stringify`.

## Closed state domain

Every live container frame is in exactly one of eight states:

- `ArrayFirstOrEnd`, `ArrayValue` or `ArrayCommaOrEnd`;
- `ObjectFirstKeyOrEnd`, `ObjectKey`, `ObjectColon`, `ObjectValue` or
  `ObjectCommaOrEnd`.

`JsonParseFrameState` is the only authority for their stable wire words. Its
ordered `ALL` set and exhaustive `word` projection are generated by the same
private macro as the reviver frame domains, including the compile-time proof
that the words remain consecutive from zero. The former independent integer
constants are absent.

## Persistence and admission

A frame-state local may be persisted or compared only through an opaque
`ValidatedJsonParseFrameStateLocal`. Rust requires the carrier name and its
four lifecycle methods to be `pub(super)` because the retained parser calls
those methods with inferred values. Its tuple field and both raw projections
remain child-private, and the parent has no carrier name, import or re-export.
The authority is move-only: it derives no clone, copy, equality or debug
capability. Comparisons borrow it, while frame creation and release consume it.

The only constructor emits a runtime admission check against every member of
`JsonParseFrameState::ALL`. An unknown persisted word reaches Wasm
`unreachable` before the authority is returned. The frame writer consumes a
validated authority, so initial and nested container states cross the same
admission boundary before persistence and cannot reuse that proof afterward.
A frame load immediately re-enters the boundary before any dispatch
comparison. Its proof is consumed by the child-owned final temporary-local
release, making both raw projection and proof reuse after release unspellable
from the parent.

All eight dispatch comparisons accept a borrowed validated authority and a
typed expected `JsonParseFrameState`. Consequently, emitter code cannot
transpose an arbitrary integer into a comparison or frame write. Every
transition write goes through one typed `JsonParseFrameState` store boundary;
only that boundary projects the stable word. Malformed source still follows
the ordinary JSON `SyntaxError` paths; an impossible internal state word traps
instead of being reported as malformed user input.
