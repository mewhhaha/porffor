# Complete pinned Conformance data

`IntlCompilationProfile::Conformance` and `--intl-profile conformance` select the
complete unprojected twelve-component pinned provider. The selected bundle owns
the actual image frames, captured foundations and compile-time catalogues.

Only the private `CheckedConformanceData` constructor can authorize the provider's
complete capability plan. It requires every component to carry Conformance and
checks all eight projection-capable physical payloads against their complete
pinned sources. The four remaining global authorities already admit only their
complete source data. Existing same-owner and dependency checks still precede
publication, followed by actual supported-values catalogue validation. A valid
checksum or changed profile label cannot authorize projected Custom data.

This is the complete current pinned provider data, not a compiler test verdict.
The internal English timezone-name operation retains its explicit locale
restriction; localized DateTimeFormat names use the DateTime image. Service
locale matching and fallback retain their original native owners. Minimal stays
the ordinary SDK default; non-Wasm backends reject the explicit selection.

Authored controls cover complete frame/catalogue consumption, foreign foundations,
cache separation and projected-payload refusal. Compilation, runtime controls,
cross-host reproducibility, data size and full pinned Test262 acceptance have not
been run for this source batch. Broader Custom manifest dimensions remain open.
