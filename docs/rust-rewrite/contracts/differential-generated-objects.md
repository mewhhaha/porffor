# Generated selected object probes

`object-probe-v1` is an actual bounded source algebra consumed by
`lila differential campaign --grammar object-probe-v1 --nodes N --properties N`.
Each budget is in 1–16. The constructor owns node and Symbol indices, unique
descriptor keys, selected roots and prototype links. Prototype edges point to
earlier nodes; property payloads can form arbitrary sharing and cycles. Arrays
retain their exotic indexed-property and length behavior with a null or generated
prototype. Generated descriptors never redefine Array length. Object/Array
graphs admit at most 64 generated accessor functions within the existing snapshot
budget; this bound is checked by the same constructor. Object/Array
allocation completes before any property payload is installed, and extensibility
changes occur after that node's complete descriptor list.

Deterministic SplitMix64 draws select ordinary/Array nodes, prototype links,
data/accessor descriptors, attributes, string/Symbol keys, negative zero, NaN,
bounded integers and BigInts, strings, object aliases and Symbols. Distinct Symbols
may share descriptions. The renderer returns the existing selected roots and
realm anchors to the unchanged v5 reflection harness. Getter/setter bodies print
if called, making accidental invocation observable. No new comparison model or
oracle is introduced. Native replay-input construction defers JavaScript source
admission to the existing worker frontend.

Reduction removes roots and properties, relaxes descriptor features and shrinks
payloads. Each candidate prunes unreachable source nodes and unused Symbols,
then reindexes every retained prototype, key and payload through the same checked
constructor. Complexity decreases strictly. Graph cycles and aliases are never
redirected to another surviving node. Replay keeps the original grammar, seed,
generation budgets, protocol and timeout; every candidate receives its own actual
source fingerprint in the campaign evidence.

The accepted witness records the actual v5 difference dimensions: graph and/or
ordered print transcript, or the failing backend and failure phase. A graph
mismatch cannot be exchanged for a lowering failure, worker failure or shared
failure. Its source-dependent mismatch signature is retained for each observation
but is not incorrectly required to remain equal as source shrinks. All candidates
use the existing selected worker and explicit oracle. Worker failure ends reduction
without a persistable case.

Authored controls cover invalid aliases/prototypes/descriptors, graph reindexing,
determinism and source identity, strict reduction progress, changing fingerprints
with a retained graph difference, worker-failure rejection, closed CLI budgets and
real v5 campaign replay. They remain unrun. This grammar covers selected reflection;
arbitrary user programs, class/private/proxy semantics, mutation schedules, broader
AST reduction and full T25 acceptance remain separate work. Complete static module
generation uses its separate [v4 algebra](differential-generated-modules.md).
