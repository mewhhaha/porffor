# Exact dynamic RegExp bound publication

The emitted constructor compiler consumes the same version 3 descriptor as the
static compiler and matcher. `RepeatBegin` names a dense bound slot with a zero
second operand; its paired Guard names the same slot. A bound row owns canonical
ASCII minimum digits and either canonical finite maximum digits or the closed
Unbounded kind. Finite maxima remain finite at every magnitude.

Parsing retains exact spans in the existing source-unit workspace. A separate
zero/one/many classification selects the existing optional, star, single and
consuming-plus layouts; it never becomes a repetition counter. The original
decimal spans determine the syntax error for minimum greater than maximum before
any descriptor is published. Leading zeros normalize to one zero or the first
nonzero digit. An unsuccessful Annex B brace probe publishes neither spans nor
the cursor. Decimal backreference probing retains its separate source-sized
capture-domain check and cannot supply quantifier bounds.

The private dense row queue retains the actual parser node for each emitted
counted body. Nodes, source units and that queue all precede the descriptor in
the checked compiler workspace. Publication writes one 48-byte row per slot,
copies each canonical span into its own contiguous payload, zero-pads to eight
bytes and then appends the existing named-group section. Synthesized zero/one
bounds own one ASCII digit. Capacity depends on source units and parser nodes,
never the numerical value of a bound. Failed construction retires the complete
existing private workspace; successful construction publishes the actual
immutable GC byte carrier before retiring it.

The GC byte gate authorizes every row and digit extent before reading it. It
rejects aliases, gaps, empty or noncanonical digits, reversed finite bounds,
unknown maximum kinds, nonzero unbounded fields and nonzero alignment padding.
Each state row is exactly eight-byte aligned after the 40-byte metadata and
four-byte base-1,000,000,000 limb capacities derived from the digit lengths. Its
offset and the final header size must equal that calculation.

A separate linear pass uses a bounded existing GC byte array to prove unique
dense slots, reciprocal Begin/Guard/End/Exit ownership, proper nesting and all
actual control-flow successors. Accept cannot occur within an active region.
Ordinary edges cannot cross a region boundary or enter Guard/Exit. The proof
clears its scratch GC owner before both successful admission and rejection.
Only the admitted layout exposes bound rows and state-byte length to the
matcher; relocation remains relative to the copied whole descriptor prefix.

Two Engine controls execute real JavaScript through Wasm. They construct literal
and runtime-generated nullable bounds beyond u64, preserve source/flags across
GC, exercise finite huge optional bounds and fast consuming failure, and check
exact reversed-bound SyntaxErrors followed by successful named-group/repeat
publication. They deliberately do not match astronomical required empty
repetitions: acceleration of those repetitions remains a separate obligation.

This is source-only evidence. Compilation and runtime controls have not run.
