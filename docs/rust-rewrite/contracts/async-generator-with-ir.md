# Mixed async-generator With IR

`AsyncGeneratorWithIr` is the complete mixed Await/Yield head and body owner.
Its constructor consumes source-minted ranges, checked mixed regions, the exact
source suspension tape and original invocation allocation inventory. Adjacent
phase entries, distinct resume states and the original suspension kinds must
agree before publication. The head cannot carry an outward unowned branch.

The ordinary-generator, plain async and mixed carriers own the same private
`CheckedWithObjectEnvironmentIr` proof. Its sole constructor requires one
completed `ToObject` publication, rederives the operand's actual result codomain,
checks a unique invocation head cell and checks the original child environment's
sole uninitialized slot-zero Object Environment Record. The child and invocation
slots remain separate domains. Raw rows cannot replace the proof after admission.

The With body carrier owns its object environment. A source Block stays a nested
Block with its own captured lexical cells. Source-created resume evidence retains
that original ancestry. Global metadata, throw inference, source call-flow,
state validation, suspension census and the actual native dispatcher consume
this carrier explicitly. Ordinary-generator and plain async region validators
reject it as a foreign continuation.

Five private controls use real parsed/lowered source to check exact mixed tape,
phase ranges, invocation aliases, ToObject codomain, object ownership, equal
extent protocol substitution and outward head branches. These controls and the
current source are uncompiled and unrun. Source review does not establish runtime
acceptance; mandatory joined verification follows the complete source batch.
