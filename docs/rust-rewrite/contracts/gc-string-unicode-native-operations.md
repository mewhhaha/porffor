# GC String Unicode native operations

The native String dispatcher consumes `StringCaseOperation` and `StringHtmlOperation` through `string/unicode_operations.rs`, alongside dedicated normalization and RegExp.escape entries. All semantic inputs and outputs are rooted, immutable UTF-16 GC Strings. Only a private scalar ByteArray workspace and existing immutable Unicode tables participate in normalization; no linear-memory JavaScript String representation remains in this owner.

The shared publisher counts UTF-16 units before allocating one exact String construction, repeats the same pure traversal over immutable inputs, then consumes publication. Its scalar decoder combines genuine surrogate pairs and preserves unpaired surrogates. Signed I32 GC array extents are checked before narrowing output or workspace lengths; exhausting that runtime extent is a resource trap, rather than truncated output.

Normalization performs RequireObjectCoercible and receiver ToString before reading or coercing the form. Undefined selects NFC; the four closed `StringNormalizationForm` values own spelling, decomposition-table selection and composition policy. Invalid forms publish a called-function-Realm RangeError. The existing locked ICU normalizer tables provide full recursive decomposition, canonical combining classes and composition pairs, including Hangul. Stable canonical ordering precedes blocked composition; a leading nonstarter never becomes a composition starter. NFC/NFD use canonical data and NFKC/NFKD use compatibility data. The primary algorithm is [String.prototype.normalize](https://tc39.es/ecma262/multipage/text-processing.html#sec-string.prototype.normalize).

Compiler table construction keeps each scalar's UTF-8 in a four-byte stack buffer and stores codepoints only when the same ICU normalization changes that scalar. Identity mappings require no temporary String or codepoint vectors. The immutable table layout, row order and Wasm serializer are unchanged; an exhaustive scalar-reference control compares all decomposition sequences, offsets, combining classes and composition pairs with the previous construction algorithm.

Default lower/uppercase consume the existing full case mapping tables, with original-input Final_Sigma context. Locale variants first coerce the receiver, then consume the existing complete CanonicalizeLocaleList owner, including every later list entry's validation and original abrupt values. Only the first canonical locale is selected. Empty lists use the same selected provider identity's DefaultLocale that the module publishes and the Engine validates, with the actual embedded identity as the default provider. Prefix lookup recognizes the UCD language-sensitive tr, az and lt families, falling back to und. The locale variants require the actual Intl host import for canonicalization.

Turkic I/dot and Lithuanian More_Above/After_Soft_Dotted rules inspect the original input, not previously emitted output. Combining class boundaries and the locked ICU Soft_Dotted/Cased/Case_Ignorable properties determine context; expansions and empty mappings flow through the same UTF-16 publisher. The authority is [ECMA-402 TransformCase](https://tc39.es/ecma402/#sec-transformcase), with the conditional mappings in [Unicode 16.0 SpecialCasing](https://www.unicode.org/Public/16.0.0/ucd/SpecialCasing.txt). This owner implements those UCD locale tailorings and does not add optional additional CLDR locale tailoring.

The thirteen Annex B HTML entries coerce the receiver first. Only anchor, fontcolor, fontsize and link then coerce their attribute argument. Attribute escaping replaces quotation marks with `&quot;`; it leaves other units unchanged. Tag and attribute selection are exhaustive closed native operations, and receiver content retains exact UTF-16 units. The algorithm is [CreateHTML](https://tc39.es/ecma262/multipage/additional-ecmascript-features-for-web-browsers.html#sec-createhtml).

[RegExp.escape](https://tc39.es/ecma262/multipage/text-processing.html#sec-regexp.escape) rejects any non-String input without ToString. Leading ASCII letters/digits receive a two-digit hex escape. Syntax punctuation, control escapes, other ASCII punctuators, ECMAScript whitespace/line terminators and lone surrogates follow EncodeForRegExpEscape; real astral pairs remain paired. This is a String transformation, distinct from RegExp pattern construction and matcher/compiler ownership.

Three finite Engine controls pair strict/sloppy Test262 host execution, require actual WasmAot, exact Normal262 and one exact print per cohort. They exercise Unicode results, HTML/escape units, full locale acquisition, original throws and both borrowed called-Realm error directions after public globals are replaced and restored. They are authored source only. Formatting and bounded source review do not establish Rust type correctness, executable Wasm behavior, runtime capability availability or full pinned Test262 conformance; all remain pending the later serial verification phase.
