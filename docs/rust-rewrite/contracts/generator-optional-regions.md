# Complete optional-chain suspension and Delete References

Ordinary generator optional chains consume one checked source owner for their
actual base and ordered links. The first link determines whether base evaluation
requires a Call Reference; its existing invocation owner preserves Identifier,
ordinary and private receivers. The complete base runs before the first nullish
guard. Computed keys and arguments retain their complete admitted expression
regions, including nested branches, multiple yields and delegation.

Every suspending link operand has disjoint skipped and selected source ranges,
consumed by `OrdinaryGeneratorIfIr` and its existing native region backend. A
durable live cell records whole-suffix short circuit; an ordinary undefined
intermediate Value does not clear it. Every completed Get, original callee,
receiver, spread and argument stays in existing owned activation cells across
later suspension. Source planning and lowering consume the same complete ranges.
The former one-plain-yield scalar optional producer is removed.

Delete chooses its Reference or Value destination from the actual final source
link. A terminal ordinary property passes retained raw base and key directly to
the existing `DeleteProperty` consumer, without terminal Get. A skipped chain
publishes `true`. A terminal Call completes normally and supplies `DeleteValue`.
Ordinary nonsuspending property deletion carries the same actual terminal link
in `DeleteOptionalPropertyChainIr`; its private constructor removes a genuine
final Property operation from the complete chain. The native Get and Delete
destinations share the prefix pipeline and existing object Delete operation.

The ECMAScript rules supporting this destination distinction are
[Optional ChainEvaluation](https://tc39.es/ecma262/multipage/ecmascript-language-expressions.html#sec-optional-chains-runtime-semantics-chainevaluation)
and [Delete evaluation](https://tc39.es/ecma262/multipage/ecmascript-language-expressions.html#sec-delete-operator-runtime-semantics-evaluation).

Private chain links, Super bases, async generator/iterator owners and awaited
optional terminal Delete remain explicit separate boundaries. The existing
private base Get/effect and captured Identifier transport owners are preserved.
No new JS tag, object model, GC schema or alternate runtime is introduced.

Three IR controls cover complete base-first plans, selected region ownership,
real terminal Delete carriers and remaining unsupported domains. The paired real
Wasm cohort runs in strict and sloppy modes and observes getter nonexecution,
nonconfigurable deletion, Proxy Delete, Symbol conversion once, intermediate Get,
receiver/callee identity, delegation, GC and injected whole Return/Throw through
yielding finally. These controls are authored source; compilation and runtime
verification remain mandatory before acceptance.
