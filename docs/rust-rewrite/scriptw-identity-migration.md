# scriptw identity cutover — 2026-10-20

The project is now **scriptw**, a Rust JavaScript-to-Wasm compiler. The CLI is
`scriptw`; all fourteen workspace packages use the `scriptw-` prefix, Rust
imports use `scriptw_`, environment variables use `SCRIPTW_`, and emitted host
imports use `scriptw_host`. Wasm remains the sole product compilation target.

Fixed-width binary format tags use `SCRW` plus their original service/version
suffix, preserving their eight-byte field sizes. Writers, readers and fixtures
move together. The few previously untyped header literals now have eight-byte
array types; manually encoded Wasm import names derive their byte length.

This is a coordinated clean break. Rebuild the compiler and regenerate emitted
Wasm with its matching runtime/host adapters; old artifacts and hosts cannot be
mixed across import namespaces. The default cache directory and compiler/native
fingerprint salts also have new identities, so old unproven artifacts cannot
be admitted as new ones. Explicit cache paths should use a new directory.

The [migration map](scriptw-identity-map.tsv) records the corresponding surface
changes. `scripts/check-scriptw-identity.sh` checks current paths and tokens;
CI and verification tooling use the new packages, binaries and environment
variables. Upstream dependencies, data and archives retain their original bytes
and checksums. Source-derived Intl identities are regenerated by their real
producers; the Collator's documentation-only projection has an explicit refresh
operation that verifies the original exporter and every actual data/macro file.

Historical results retain the executable and source identities that produced
them. The previous identity migration, dated evidence JSON and captured readers
are frozen by exact SHA-256 in [the history inventory](scriptw-frozen-history.json).
The audit projects old names only after verifying those original bytes. The
historical generated README publication is preserved byte for byte. New
publication output uses the scriptw identity. Renaming does not establish new
conformance, verification or performance results for this compiler revision.

Update, 2026-10-21: the repository is now
[github.com/mewhhaha/scriptw](https://github.com/mewhhaha/scriptw); the former URL
redirects there. The external `porffor.dev` domain remains unchanged. Retiring the
two obsolete backend scaffolds reduces the workspace from fourteen to twelve
packages; the identity cutover above records the original fourteen-package state.
